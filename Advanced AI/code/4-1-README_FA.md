# برنامه تحلیل جامع آماری مقاومت فشاری بتن

## اجرا
1. Python 3.10 یا جدیدتر نصب کنید.
2. در پوشه برنامه اجرا کنید:
   `python -m pip install -r requirements.txt`
3. اجرای تحلیل با دریافت داده از UCI:
   `python concrete_distribution_analysis.py`
4. برای پوشه خروجی دلخواه:
   `python concrete_distribution_analysis.py --output-dir results`
5. برای داده محلی:
   `python concrete_distribution_analysis.py --data Concrete_Data.xls --output-dir results`
6. برای اجرای سریع‌تر و حذف بوت‌استرپ:
   `python concrete_distribution_analysis.py --bootstrap 0`

## خروجی
`final_report.html` گزارش نهایی با جدول‌ها و نمودارهاست. همچنین CSVهای آمار توصیفی، برازش توزیع‌ها، توزیع منتخب اولیه، آزمون‌های نرمال‌بودن، ماتریس همبستگی/کوواریانس، روابط ورودی–مقاومت، PCA، معیارهای مدل و پیش‌بینی‌های اعتبارسنجی متقاطع تولید می‌شوند. نمودارهای PNG شامل هیستوگرام و توزیع برازش‌شده، Q–Q، مقایسه AIC/BIC، heatmap، نمودارهای زوجی، PCA، روابط ورودی–هدف و تشخیص باقیمانده‌ها هستند.

## روش و محدودیت‌ها
- توزیع اولیه با کمترین BIC انتخاب می‌شود و AIC و آزمون‌های برازش نیز گزارش می‌شوند؛ این رتبه‌بندی اثبات‌کننده توزیع حقیقی نیست.
- p-value معمول KS برای پارامترهای برازش‌شده روی همان نمونه دقیقاً کالیبره نیست؛ برنامه بوت‌استرپ پارامتری KS را نیز اجرا می‌کند.
- آمار Anderson–Darling فقط برای نامزد نرمال گزارش می‌شود.
- توزیع بتا با مقیاس‌کردن به بازه کمینه/بیشینه مشاهده‌شده برازش می‌شود؛ این روش توصیفی است.
- پواسون برای داده‌های پیوسته مانند مقاومت بتن مناسب نیست و با نامزدهای پیوسته مقایسه نمی‌شود.
- همبستگی و PCA توزیع مشترک کامل را تعیین نمی‌کنند و همبستگی به معنی علیت نیست.
- مدل Ridge یک مدل پایه است و به‌تنهایی اعتبارسنجی مهندسی مستقل محسوب نمی‌شود.
